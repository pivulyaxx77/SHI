# RP Rules AI Bot (Python)

AI бот для відповідей на питання по правилах сервера UKRAINE RP Emergency Hamburg.

## Можливості
- автоматично завантажує правила з сайту
- відповідає тільки на питання по RP
- використовує Google Gemini API
- має простий веб-інтерфейс

## Встановлення

1. Клонувати репозиторій
2. Встановити залежності

pip install -r requirements.txt

3. Створити файл .env

GEMINI_API_KEY=YOUR_API_KEY

4. Запустити сервер

python app.py

5. Відкрити

http://localhost:5000
